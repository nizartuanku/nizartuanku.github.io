FMC/FTD Health Check: what to send

Thank you for your order. This page lists the exports we need for the review, how to remove secrets before you share them, and what happens next. Collecting everything usually takes 20 to 30 minutes.

Applies to Secure Firewall Management Center (FMC) 7.x with managed FTD devices · scope: 1 FMC and up to 4 FTD devices

Ground rules

  • Never send passwords, keys, certificates with private keys, or remote access. We do not log in to your systems. The review uses only the files you choose to share.
  • Read-only commands only. Nothing on this page changes your configuration.
  • Menu paths can differ slightly between FMC releases. If a menu is not where we say, use the closest equivalent and tell us in the chat.

1. From the FMC (screenshots or exports)

  1. FMC version: Help > About.
  2. Managed devices: Devices > Device Management. A screenshot or CSV showing each device's model, software version, and HA or cluster membership.
  3. Content versions: System > Updates. The installed VDB, rule update (SRU/LSP) and geolocation versions.
  4. Health: System > Health > Monitor. A screenshot of the summary, plus any device that shows a warning or critical alert.
  5. Access control policy report: Policies > Access Control, then the report icon next to each deployed policy. The PDF report.
  6. Backups: System > Tools > Backup/Restore. A screenshot of the backup list with dates.
  7. Licensing: System > Licenses > Smart Licenses. A screenshot of the status page.

2. From each FTD device (CLI)

Connect to the device console or SSH (the normal FTD CLI, not expert mode) and save the output of these commands to one text file per device:

show version
show managers
show failover
show cluster info
show interface ip brief
show cpu usage
show memory
show conn count
show access-control-config
show running-config

If a command returns an error on your release, leave it out and continue. A missing line is fine; a guessed one is not.

3. Remove secrets before you send

FTD masks most secrets in show running-config, but check before you share. Search each file for these words and replace the value after them with REMOVED:

pre-shared-key   key   password   secret
community        authentication   ldap-login-password
username         enable

Optional: if you do not want to share real public IP addresses, replace each one with a consistent placeholder (for example PUBLIC-IP-1). Use the same placeholder everywhere the same address appears, so the review still makes sense.

4. How to send it

  1. Put everything in one ZIP file named after your company or project.
  2. Open the support chat on Whop and attach the ZIP, or ask there for a private upload link if the file is too large.
  3. Tell us your target FMC/FTD release, if you already have one in mind.

What happens next

  • We confirm the files are complete within one business day, or tell you exactly what is missing.
  • You receive the PDF report and upgrade runbook within 5 business days of a complete set.
  • You can ask up to 10 follow-up questions in writing within 14 days of delivery.
  • Your files are deleted within 30 days of delivery.
